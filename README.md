# ShelfShare

**ShelfShare** — это клиент-серверное веб-приложение для организации буккроссинга (обмена книгами) через уличные шкафчики. Пользователи могут находить ближайшие шкафчики, добавлять в них книги, забирать понравившиеся экземпляры и оставлять отзывы.

## 🎯 Цель проекта
Создание платформы, которая упрощает обмен книгами между людьми, делает буккроссинг удобным и отслеживаемым.

## 🛠 Технологический стек
- **Backend:** ASP.NET Core, Entity Framework Core
- **Frontend:** React (или Vue)
- **База данных:** PostgreSQL
- **DevOps:** Docker, Nginx
- **Документация:** Markdown, Mermaid, Swagger
