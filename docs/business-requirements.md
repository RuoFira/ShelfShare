# Бизнес-требования — ShelfShare

## 1. Описание проекта

**ShelfShare** — веб-приложение для сети общественных книжных шкафов (Little Free Library).

Пользователи могут:
- Находить книжные шкафчики рядом с собой
- Смотреть, какие книги сейчас находятся в шкафчике
- Добавлять книги в шкафчик
- Забирать книги из шкафчика
- Оставлять отзывы о книгах
- Добавлять книги в список желаний
- Сообщать о проблемах (жалобы)

## 2. Целевая аудитория

- Жители города, которые хотят бесплатно брать и оставлять книги
- Волонтёры, которые следят за шкафчиками
- Модераторы / администраторы системы

## 3. Основные роли пользователей

| Роль            | Возможности                                      |
|-----------------|--------------------------------------------------|
| Гость           | Просмотр шкафчиков и книг                        |
| Пользователь    | Добавление/забор книг, отзывы, wishlist, жалобы  |
| Модератор       | Обработка жалоб, удаление неподходящего контента |
| Администратор   | Управление пользователями и шкафчиками           |

## 4. Основные бизнес-правила

1. Один экземпляр книги может находиться только в одном шкафчике одновременно.
2. При заборе книги создаётся запись о перемещении.
3. Пользователь может оставлять отзывы только на книги, которые он брал.
4. Жалобы рассматриваются модераторами.
5. Нельзя добавлять книги 18+ без соответствующей пометки.
6. Шкафчик должен иметь координаты (широта и долгота).

## 5. Цели проекта

- Сделать процесс обмена книгами удобным и прозрачным
- Собирать статистику по популярности книг и шкафчиков
- Дать возможность отслеживать «путешествие» книги по городу
