# Use Cases — ShelfShare

## Основные варианты использования

### UC-01. Просмотр списка шкафчиков
**Актёр:** Гость / Пользователь  
**Описание:** Пользователь открывает главную страницу и видит список общественных книжных шкафчиков.

### UC-02. Просмотр шкафчика и книг в нём
**Актёр:** Гость / Пользователь  
**Описание:** Пользователь выбирает шкафчик и видит, какие книги сейчас в нём находятся.

### UC-03. Добавление книги в шкафчик
**Актёр:** Пользователь  
**Предусловие:** Пользователь авторизован  
**Описание:** Пользователь добавляет новую книгу в выбранный шкафчик (указывает название, автора, состояние).

### UC-04. Забор книги из шкафчика
**Актёр:** Пользователь  
**Предусловие:** Пользователь авторизован  
**Описание:** Пользователь забирает книгу из шкафчика. Система создаёт запись о перемещении.

### UC-05. Поиск книг
**Актёр:** Гость / Пользователь  
**Описание:** Пользователь ищет книгу по названию или автору и видит, в каких шкафчиках она есть.

### UC-06. Оставление отзыва на книгу
**Актёр:** Пользователь  
**Описание:** Пользователь ставит оценку и пишет комментарий к книге.

### UC-07. Добавление книги в Wishlist
**Актёр:** Пользователь  
**Описание:** Пользователь добавляет книгу в список желаний.

### UC-08. Создание жалобы
**Актёр:** Пользователь  
**Описание:** Пользователь сообщает о проблеме (неподходящая книга, повреждённый шкафчик и т.д.).

### UC-09. Модерация жалоб
**Актёр:** Модератор  
**Описание:** Модератор просматривает жалобы и принимает решение (удалить контент / отклонить жалобу).

### UC-10. Регистрация и вход
**Актёр:** Гость  
**Описание:** Пользователь создаёт аккаунт или входит в систему.
