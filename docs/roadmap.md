# Roadmap и график работ — ShelfShare

## Текущий статус

Проект выполняется одним человеком. Все роли совмещены.

## График работ

### 2-я лабораторная (текущий чекпоинт)

**Цель:** Анализ задачи + первичный дизайн + Hello World

Что должно быть готово:
- [x] Создан GitHub-репозиторий
- [x] Структура проекта (backend / frontend / docs)
- [x] Бизнес-требования
- [x] Список сущностей
- [ ] ERD-диаграмма
- [ ] API-контракты (черновик)
- [ ] Hello World Backend (ASP.NET Core)
- [ ] Hello World Frontend (React)
- [ ] Базовый README

### 3-я лабораторная

**Цель:** Рабочее приложение с основным функционалом

Планируемый функционал:
- Регистрация и авторизация пользователей
- CRUD книжных шкафчиков
- Добавление и забор книг
- Просмотр книг в шкафчике
- Отзывы на книги
- Список желаний (Wishlist)
- Жалобы (Reports)
- Простой поиск по книгам и шкафчикам
- Базовый адаптивный интерфейс

## Roadmap развития (после 3-й лабы)

### Версия 1.1
- Карта с шкафчиками (Leaflet / Yandex Maps)
- Загрузка фотографий шкафчиков и книг
- Уведомления

### Версия 1.2
- Статистика (самые популярные книги, активные шкафчики)
- История перемещений книги («путешествие книги»)
- Модераторская панель

### Версия 2.0
- Мобильная версия / PWA
- Рекомендации книг
- Система достижений
